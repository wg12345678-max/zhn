# 实验教学目标

## 一、知识目标

通过本实验，学生应掌握以下核心知识：

1. **数据治理基础**：数据质量评估、异常识别与处理、PII 脱敏技术（掩码/截断/替换/加密）与适用场景；
2. **数据分类分级**：按敏感程度与业务价值对数据进行分类分级，匹配差异化保护策略；
3. **合规法规要点**：《个人信息保护法》《数据安全法》《著作权法》《企业数据资源相关会计处理暂行规定》的核心条款与落地要求；
4. **数据资产入表**：数据资产确认的四项条件、成本计量方法、估值逻辑（基础价值→质量溢价→稀缺溢价→合规折损）；
5. **训练数据治理**：个保法合规、数据安全合规、版权合规三重审查框架与审查要点。

## 二、能力目标

1. **工程设计能力**：能针对给定数据源设计完整的数据治理方案（清洗→脱敏→分级→报告）；
2. **决策分析能力**：能在合规、业务、财务、算法四方利益冲突中，基于 KPI 量化结果做出权衡决策；
3. **风险预判能力**：能识别数据流转中的合规风险点，预判决策后果；
4. **工具应用能力**：能操作虚拟仿真系统完成数据体检、合规博弈、资产入表全流程；
5. **反思优化能力**：能根据 KPI 反馈迭代优化决策，形成闭环改进。

## 三、素养（思政）目标

1. **法治意识**：树立"合规是数据治理底线"的职业信念，理解数据安全是企业社会责任；
2. **工匠精神**：培育"质量至上、精益求精"的数据治理态度——每一条数据的脱敏、每一份报告的审核，都关乎企业信誉与公共利益；
3. **责任意识**：理解数据治理岗位对企业数字化转型的支撑作用，增强职业使命感；
4. **伦理自觉**：在 AI 训练中坚持"合法合规优先"，抵制为追求模型效果而忽视版权与隐私的短视行为；
5. **协同意识**：体会数据治理是跨部门协作，合规、业务、财务、算法四方需协同而非对立。
