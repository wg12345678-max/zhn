# 实验结果与结论

## 一、实验结果呈现

实验结束后，系统向学生呈现以下结果：

### 1. 20 步操作得分明细

按实验步骤（20步）逐项展示得分、满分、判定依据，学生可回溯每一步的对错与扣分原因。

### 2. 四维能力画像

| 能力维度 | 计算依据 | 等级标准 |
|---|---|---|
| 数据质量 | 步骤 3-9（数据源选择、数据生成、异常识别与处理、脱敏） | ≥85 卓越 / ≥75 优秀 / ≥60 良好 / <60 待提升 |
| 合规判断 | 步骤 10-14、18-19（合规博弈、事件应对、训练集审查） | ≥85 卓越 / ≥75 优秀 / ≥60 良好 / <60 待提升 |
| 资产运营 | 步骤 15-17（估值理解、入表条件、入表申请） | ≥85 卓越 / ≥75 优秀 / ≥60 良好 / <60 待提升 |
| AI 协同 | 步骤 2、20（设备认知、能力画像总结） | ≥85 卓越 / ≥75 优秀 / ≥60 良好 / <60 待提升 |

四维能力以雷达图可视化呈现，学生可直观识别自身优势与短板。

### 3. 综合得分与岗位映射

- 综合得分 = 四维能力加权平均（百分制）；
- 岗位映射：综合得分对应不同岗位等级，从"数据录入员"到"首席数据官"。

### 4. 能力认证

综合得分或单维得分达到阈值，即获得对应认证：

- 综合 ≥60：数据治理专员（入门）
- 综合 ≥75：数据治理工程师（良好）
- 综合 ≥85：数据治理专家（优秀）
- 合规判断 ≥80：合规审计师（卓越）
- 资产运营 ≥80：数据资产运营官（卓越）

### 5. 完整实验报告

系统自动生成包含 20 步得分、四维能力、岗位映射、能力认证、实验备忘录的完整报告，支持下载与提交。

## 二、典型实验结论分支

学生的不同决策组合会导向不同结果，形成多路径结论：

| 决策路径 | 结果分支 | 结论含义 |
|---|---|---|
| 脱敏完整 + 四条件满足 + 三重审查通过 + 决策允许 | **成功入表 + 训练集准入** | 数据资产化全流程合规，价值最大化 |
| 脱敏漏项 | **被规则引擎硬拦截** | 个保法合规是底线，漏脱敏即违规 |
| 四条件不全满足仍提交入表 | **入表申请被驳回** | 数据资产确认条件缺一不可 |
| 合规严格度过高 | **业务 KPI 偏低** | 过度合规牺牲业务效率，需平衡 |
| 合规严格度过低 | **合规 KPI 偏低 + 触发监管事件** | 合规底线失守，风险与处罚上升 |
| 三重审查有任意一项不通过仍允许训练 | **决策错误（0分）** | 训练数据合规是 AI 伦理底线 |
| 滑块迭代后改进 | **二次提交得分提升** | 形成"决策—反馈—优化"闭环 |

## 三、实验结论

通过本实验，学生应形成以下核心结论：

1. **合规是数据治理的底线**：个保法、数安法、版权合规是硬约束，任何环节违规都会被规则引擎拦截，不存在"擦边"空间；
2. **数据资产化是有条件的确认**：数据资源需同时满足"拥有或控制、预期经济利益、成本可靠计量、合规审查通过"四项条件，缺一不可；
3. **权衡是数据治理的日常**：合规、业务、财务、算法四方利益冲突客观存在，优秀的数据治理不是"选边站"，而是在底线之上寻求最优平衡；
4. **训练数据合规是 AI 伦理的守门人**：含未脱敏 PII、来源不明的爬虫数据、版权不明数据均不得进入训练集；
5. **试错是成长的路径**：虚拟仿真允许反复试错，每一次"被拦截"都是对法规条款与治理逻辑的深层理解。

## 四、拓展思考

实验结束后，教师可引导学生进一步思考：

- 若数据同时涉及跨境流转，合规要求会如何变化？
- 如何在合规底线之上，设计更具创新性的数据产品？
- 面对新型 AI 风险（如模型投毒、提示注入），现有规则引擎需如何升级？
- 数据资产的摊销与减值应如何计量？
