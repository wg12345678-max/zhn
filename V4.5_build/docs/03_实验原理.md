# 实验原理

## 一、核心仿真对象

本实验仿真的是"AI 企业数据资产化与合规治理"全流程，包含三大模块：

- **模块一·数据体检**：多源数据清洗、脱敏、分类分级，生成异常工单；
- **模块二·合规博弈**：在合规、业务、财务、算法四方利益冲突中做权衡决策，应对突发事件；
- **模块三·资产判断**：完成数据资产估值、入表条件判断、训练集准入审查。

## 二、规则引擎 + LLM 双轨机制

本实验采用"规则引擎 + 大语言模型"双轨赋能架构：

### 1. 规则引擎（保底线）

- 基于《个保法》《数安法》《著作权法》《数据资产入表暂行规定》构建硬约束规则库；
- 对学生操作进行实时判定：合规即通过，违规即硬拦截并给出法条依据；
- 保证评价的确定性、可解释性、可复现性。

### 2. LLM 学伴（提认知）

- 基于 RAG（检索增强生成）技术，从法规知识库与产业案例库检索相关法条与案例；
- 为学生提供法条引用、卡壳提示、决策追问、实验报告辅助生成；
- 在规则引擎判定之外，补充情境化解释与开放性问题引导。

### 3. 双轨协同

- **规则保底线**：所有操作先过规则引擎，违规必拦截；
- **模型提认知**：规则判定后，LLM 给出"为什么""还可以怎么做"的解释；
- **LLM 不替代规则**：开放性问题上 LLM 可补充，但合规性判定以规则引擎为准，避免大模型幻觉导致的错误放行。

## 三、成德产业指纹模型

- 合成数据生成器内置成德高端能源装备产业关键词库（汽轮机叶片、燃气轮机、风电齿轮箱、焊接工艺 WPS、合金钢锭等）；
- 五类数据源（研发图纸、工艺参数、供应链 BOM、售后日志、能耗监测）各有专属标签分布，使合成数据具备产业辨识度；
- 跨域流转标记（成都→德阳、德阳本地、德阳→全国）体现产业集群真实协作模式。

## 四、数据资产入表原理

数据资源确认为数据资产需同时满足四项条件：

1. **企业拥有或控制**：数据来源合法，企业对其有实际控制权；
2. **预期带来经济利益**：数据可对外提供服务或内部使用产生价值；
3. **成本可靠计量**：数据获取与治理成本可可靠计量；
4. **合规性审查通过**：数据来源、处理、使用全过程合规。

估值逻辑采用"基础价值→质量溢价→稀缺溢价→合规折损→最终估值"的瀑布模型。

## 五、知识点清单

| 模块 | 核心知识点 | 对应法规/标准 |
|---|---|---|
| 数据体检 | 数据质量维度（完整性、准确性、一致性、及时性） | GB/T 36344 数据质量 |
| 数据体检 | PII 识别与脱敏（掩码/截断/替换/加密） | 《个人信息保护法》 |
| 合规博弈 | 合规、业务、财务、算法四方利益冲突模型 | 《数据安全法》 |
| 合规博弈 | 数据泄露、政策突变等突发事件应对 | 应急预案管理 |
| 资产入表 | 数据资产确认四条件、成本计量 | 《企业数据资源相关会计处理暂行规定》 |
| 资产入表 | 数据资产估值瀑布模型 | 资产评估准则 |
| 训练集审查 | 个保法/数安法/版权三重合规审查 | 《个保法》《数安法》《著作权法》 |

## 六、能力画像与岗位映射原理

- 系统按 20 步操作轨迹，计算**数据质量、合规判断、资产运营、AI 协同**四维能力得分；
- 四维得分加权平均得出综合得分；
- 综合得分映射对应岗位（数据录入员→治理助理→治理工程师→高级治理工程师→首席数据官）；
- 能力认证条件：综合得分或单维得分达到阈值即获得对应认证（数据治理专员/工程师/专家、合规审计师、数据资产运营官）。
