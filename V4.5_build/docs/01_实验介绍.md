# 实验介绍

## 一、实验背景

随着《数据安全法》《个人信息保护法》《企业数据资源相关会计处理暂行规定》相继落地，数据已从"IT 资源"升级为"生产要素"，数据资产化与合规治理成为企业数字化转型的核心命题。成德高端能源装备产业集群（成都研发设计、德阳生产制造）跨域数据流转频繁，涉及汽轮机叶片图纸、风电齿轮箱工艺参数、供应链 BOM 等核心数据，其治理与合规直接关系产业安全与资产价值。

然而，这一真实场景存在三个"教学不可达"痛点：

1. **敏感不可试错**：真实企业数据含客户身份证、工艺秘密，一旦泄露后果严重，企业不敢让学生接触真实数据；
2. **流程不可复现**：数据资产入表、训练集审查是低频高价值决策，课堂上无法反复演练；
3. **冲突不可体会**：合规、业务、财务、算法四方利益冲突，只有真正"做决定"才能理解博弈张力。

## 二、为什么"能实不虚"

| 真实场景难点 | 虚拟仿真解法 |
|---|---|
| 真实数据含个人信息，不可给学生使用 | 用带成德产业指纹的**合成数据**替代，零真实 PII 风险 |
| 脱敏策略选错可能违法 | 系统**硬拦截**+即时反馈，可反复试错 |
| 数据资产入表决策不可逆 | 虚拟环境**随时重置**，支持多轮决策对比 |
| 合规与业务冲突难以量化 | **四方 KPI 实时可视化**，调整即见后果 |
| 训练集投毒后果滞后 | 系统**模拟投毒结果**，即时暴露风险 |

## 三、实验定位

本实验属于**综合设计型**虚拟仿真实验，学生不是被动观察流程，而是：

- **自主式**：自选角色、自选数据源、自选脱敏策略、自选权衡决策；
- **交互式**：20 步实质性操作，每步有输入、有反馈、有后果；
- **设计·探究·应用融合**：先设计治理方案，再探究冲突根源，最终应用规则完成资产入表与训练集审查。

## 四、预期成效

通过本实验，学生能够：

- 掌握数据清洗、脱敏、分类分级的标准流程与技术选型；
- 理解合规、业务、财务、算法四方冲突的量化权衡方法；
- 具备数据资产估值与入表条件判断能力；
- 形成"数据合规是底线、数据资产是价值"的职业认知，培育"守底线、精治理、善运营"的数字经济工匠精神。
