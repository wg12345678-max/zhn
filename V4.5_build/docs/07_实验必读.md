# 实验必读

> 学生在开展实验前，请务必阅读以下运行环境与操作要求，确保实验顺利进行。

## 一、网络要求

| 项目 | 要求 |
|---|---|
| 网络类型 | 有线宽带 / Wi-Fi / 4G/5G 均可 |
| 推荐带宽 | ≥ 5 Mbps（下行） |
| 最低带宽 | ≥ 2 Mbps |
| 网络延迟 | ≤ 200 ms |
| 稳定性 | 实验过程中不建议切换网络或断开重连 |
| 并发说明 | 实验空间采用排队与并发控制机制，高峰期可能需短暂等待 |
| 接口联通 | 需能正常访问实验空间（iLab-X）平台及本项目服务接口 |

> **提示**：若实验中出现卡顿，优先检查网络带宽与延迟，而非反复刷新页面。

## 二、硬件要求

| 项目 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | Intel i3 / AMD 同级（双核 2.0GHz） | Intel i5 / AMD 同级（四核 2.5GHz 及以上） |
| 内存 | 4 GB | 8 GB 及以上 |
| 硬盘可用空间 | 2 GB | 5 GB 及以上 |
| 显卡 | 集成显卡即可 | 独立显卡（非必需，仅提升 3D 渲染流畅度） |
| 显示器分辨率 | 1280×720 | 1920×1080 及以上 |
| 外设 | 键盘、鼠标 | 键盘、鼠标 |

> **说明**：本实验以 Web 端交互为主，**无需高性能显卡**，普通办公电脑即可流畅运行。

## 三、用户操作系统要求

| 项目 | 支持情况 |
|---|---|
| Windows | Windows 10 / 11（推荐） |
| macOS | macOS 10.15（Catalina）及以上 |
| Linux | Ubuntu 18.04 及以上（桌面版） |
| ChromeOS | 支持（通过 Chrome 浏览器） |

## 四、浏览器与插件要求

| 项目 | 要求 |
|---|---|
| 推荐浏览器 | Google Chrome（最新版） |
| 支持浏览器 | Microsoft Edge、Mozilla Firefox、Safari（最新版） |
| 浏览器版本 | 近 3 年内发布的主流版本 |
| 插件 | **无需安装任何插件** |
| 脚本 | 需启用 JavaScript（默认开启，请勿禁用） |
| Cookie | 建议允许实验空间域名 Cookie |
| 弹窗 | 允许实验空间域名的弹窗（用于实验报告下载） |

> **提示**：不建议使用 IE 浏览器及早期 Edge（非 Chromium 内核）版本，可能存在兼容性问题。

## 五、账号与登录要求

| 项目 | 说明 |
|---|---|
| 账号类型 | 匿名账号（dg001 - dg200） |
| 个人信息采集 | **不采集学生姓名、学号等真实身份信息** |
| 登录方式 | 实验空间统一认证入口 |
| 账号获取 | 由任课教师或实验空间统一分配 |
| 会话时长 | 单次实验建议 90 分钟内完成，超时系统自动保存进度 |
| 多终端 | 支持同一账号在不同终端续做，但同一时间仅限单终端登录 |

## 六、实验时长建议

| 环节 | 建议时长 |
|---|---|
| 实验准备与认知 | 7 分钟 |
| 数据体检 | 25 分钟 |
| 合规博弈 | 20 分钟 |
| 资产入表与训练集审查 | 20 分钟 |
| 总结反思与报告提交 | 18 分钟 |
| **合计** | **约 90 分钟（2 学时）** |

## 七、操作注意事项

1. 实验过程中**不要强制刷新或关闭浏览器**，否则可能导致当前步骤进度丢失；
2. 系统每完成一步自动保存，如遇断网，恢复后可从最近完成步骤继续；
3. 关键决策（如入表申请、训练集准入）**提交后不可撤回**，请确认无误后再提交；
4. 如遇系统提示"连续答错 3 次给出答案"，属正常学习机制，该步得分不计入；
5. 实验报告提交后，可在"我的实验报告"中查看与下载。

## 八、常见问题（FAQ）

| 问题 | 解决方案 |
|---|---|
| 页面打不开 / 白屏 | 检查网络 → 更换浏览器 → 清除缓存后重试 |
| 步骤卡住无法下一步 | 确认是否已完成当前步骤所有必填项，或刷新后从最近步骤继续 |
| 滑块拖动无响应 | 检查浏览器是否禁用 JavaScript，或尝试更换浏览器 |
| 实验报告下载失败 | 允许浏览器弹窗，或更换下载路径 |
| 账号登录提示异常 | 联系任课教师或实验空间客服核对账号状态 |
