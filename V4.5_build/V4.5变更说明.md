# V4.5 变更说明

## 版本定位

V4.5 在 V4.3 技术框架稳定的基础上，**重点补全实验空间网页展示层**——即配棉工艺实验页面上的"实验介绍 / 实验教学目标 / 实验原理 / 实验教学过程与实验方法 / 实验步骤 / 实验结果与结论 / 实验必读"等页面文案与元数据。此前版本仅有系统代码与数据，缺少面向实验空间平台展示的实验信息。

## 新增内容

新增 `docs/` 目录，包含 8 个展示层文档：

| 文件 | 内容 | 对标配棉实验 |
|---|---|---|
| `00_页面元数据.md` | 上线时间、所属专业类、对应专业、课程类型、实验类型、所属课程 | 页面头部字段 |
| `01_实验介绍.md` | 为什么"能实不虚"——成德跨域数据不可在真实产线试错 | 配棉"设备庞大危险，实践无法实现" |
| `02_实验教学目标.md` | 知识 / 能力 / 素养（思政）三维目标 | 实验教学目标 |
| `03_实验原理.md` | 规则引擎+LLM双轨、成德产业指纹、数据资产入表原理、知识点清单 | 实验原理 |
| `04_实验教学过程与实验方法.md` | 自主式+交互式、三角色、随机事件、AI导学、过程评价 | 实验教学过程与实验方法 |
| `05_实验步骤（20步）.md` | 20步交互清单（名称/目标/用时/赋分模型/满分/成绩类型） | 实验步骤 |
| `06_实验结果与结论.md` | 各分支决策结果 + 核心结论 + 拓展思考 | 实验结果与结论 |
| `07_实验必读.md` | 网络/硬件/操作系统/浏览器/账号/时长/FAQ | 实验必读 |

## 技术调整

- **`reporting/ability_portrait.py`**：`plotly` 由顶层 import 改为延迟导入（函数内导入）。当环境未安装 plotly 时，模块可正常加载、雷达图函数返回 `None`，不再因缺包导致整个模块崩溃；部署环境安装 plotly 后自动生效。
- **`smoke_test.py`**：第 7 项测试（报告导出）适配 plotly 可选依赖——未装 plotly 时仅验证函数不抛异常、返回 `None`；已装时验证图对象有效。

## 使用方式

```bash
pip install -r requirements.txt      # 建议补充安装 plotly（可选）
python database.py                   # 建库 + 烧录200账号
python smoke_test.py                 # 冒烟测试 10/10
streamlit run main_app.py
```

## 注意事项

- `docs/` 下 8 个 md 为**实验空间页面文案**，可直接复制粘贴到实验空间后台对应栏目；
- `00_页面元数据.md` 中的"上线时间""项目负责人"等字段待你确认后填入；
- 若部署环境无 plotly，雷达图功能不生效，但其余所有功能正常运行，不影响实验主流程。
